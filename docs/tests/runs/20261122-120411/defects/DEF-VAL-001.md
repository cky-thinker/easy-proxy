# DEF-VAL-001 静态校验脚本未自动闭环运行证据

## 现象

静态校验全部 16 项通过，但脚本只创建运行目录、原始证据和“进行中”的清单，未自动写入结束时间与最终状态、生成正式报告、登记报告索引或生成 `SHA256SUMS.txt`。

## 影响

该轮不能作为可追溯的最终通过轮次；若人工补齐，容易遗漏索引或哈希，不符合方案 9.7 节“每轮必须有清单、原始证据校验、最终报告并可追溯”的要求。

## 修复

更新 `docs/tests/scripts/validation/validate-test-assets.ps1`，在正常结束和判定失败时均自动生成报告、更新索引、写入最终清单并生成哈希，最后再以退出码反映判定。

## 回归要求

使用新的运行编号在干净运行目录重新执行，并核验报告、索引、清单、哈希和最终状态全部自动闭环。本失败轮次保留，不覆盖、不删除。
