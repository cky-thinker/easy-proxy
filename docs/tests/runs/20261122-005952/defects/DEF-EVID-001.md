# DEF-EVID-001 测试运行日志未被 Git 跟踪且历史证据缺口未闭环

## 基本信息

| 字段 | 值 |
| --- | --- |
| 缺陷编号 | `DEF-EVID-001` |
| 严重级别 | P2 |
| 首次发现运行 | `20261122-005952` |
| 触发用例 | T-37 及测试资产静态校验 |
| 修复提交 | `ddb5520760a5dfa73cddb1f475fe2a2af0058685` |
| 验证运行 | `20261122-020926` |
| 状态 | 已关闭 |

## 现象

仓库中的 `*.log` 全局忽略规则使 `docs/tests/runs/**/raw/**` 下的构建、Maven 和校验日志无法被 Git 跟踪。部分早期运行还缺少正式报告、运行清单、校验和或缺陷记录，导致失败证据只能保存在本地，难以按提交追溯和回滚。

## 影响范围

- T-37 的原始构建输出不能随代码提交一起归档。
- 中间失败轮次无法从仓库中完整还原和复核。
- 静态校验能够识别表面缺失，但无法替代人工确认日志是否含凭据。

## 根因

全局日志忽略规则优先于测试运行目录约定，且归档流程未在任何构建前强制检查运行清单、报告、校验和与缺陷记录的完整性。

## 修复说明

- 为 `docs/tests/runs/**/raw/**/*.log` 增加忽略例外。
- 补齐中间轮次的运行清单和报告，登记报告索引。
- 为历史运行生成 `SHA256SUMS.txt`。
- 对全部新纳入跟踪的日志执行凭据扫描。
- 后续正式运行继续执行清单、报告、哈希和脱敏复核。

## 验证证据

- 日志原始证据：`docs/tests/runs/20261122-005952/raw/build/`、`docs/tests/runs/20261121-235500/raw/build/`
- 静态校验结果：`docs/tests/runs/20261122-020926/raw/validation/test-assets-validation.txt`。
- 凭据扫描：23 份构建日志全部通过，未发现私钥、令牌、密码或认证头。

## 回归范围

- Git 跟踪和忽略规则。
- 测试运行目录的清单、报告、缺陷记录和哈希归档。
- 后续所有构建、发布、部署与容量测试的证据采集。
